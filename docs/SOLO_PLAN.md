## 4. Ядро крупным планом: что именно ты защищаешь

### 4.1 Три формулы, которые надо уметь вывести на бумаге

1. **Гипербола пролёта.** `e = 1 + r_p·v∞²/μ` — из vis-viva в перицентре:
   `v_p² = v∞² + 2μ/r_p` и `v_p² = μ(2/r_p + 1/a)`, `a = -μ/v∞²`, `e = 1 - r_p/a`.
2. **Угол поворота.** `δ = 2·arcsin(1/e)` — из геометрии гиперболы: асимптоты
   наклонены под углом `ν∞ = arccos(-1/e)` к оси, поворот вектора скорости равен
   `π - 2·(π - ν∞) = 2ν∞ - π = 2·arcsin(1/e)`.
3. **«Треугольник скоростей».** `v_out² = v_J² + v∞² - 2·v_J·v∞·cos δ` — теорема косинусов
   для суммы гелиоцентрической скорости планеты и вектора `v∞` на выходе.
   Из неё же — условие ухода: `v_out ≥ v_esc` ⇒ `δ_нужн = 164.32°`.

### 4.2 Четыре числа, которые надо знать наизусть

| Число | Что это |
|---|---|
| **138.98°** | максимальный поворот у Юла (пролёт по касательной к атмосфере, h_p = 200 км) |
| **87.31°** | поворот, который «бесплатно» закидывает аппарат на афелий Эилу (h_p = 35 096 км) |
| **164.32°** и **58.9 м/с** | сколько нужно для ухода из системы и сколько стоит недостача (импульс Оберта в перицентре) |
| **10.1 R_J** и **0.02–0.03°** | перицентр «Вояджера-2» у Юпитера и расхождение модели с эфемеридами NASA |

### 4.3 Скрипт-минимум: 35 строк, которые надо набрать руками

Набери (не копируй — именно набери) и запусти. Он воспроизводит все ключевые числа
проекта **без единого импорта кроме `math`**, то есть без numpy, scipy и всего репозитория:

```python
import math
MU_SUN, MU_JOOL = 1.1723328e18, 2.82528e14
A_JOOL, R_JOOL  = 68.773560320e9, 6.0e6
v_j   = math.sqrt(MU_SUN / A_JOOL)          # скорость Юла на орбите
v_esc = math.sqrt(2 * MU_SUN / A_JOOL)      # уход из системы Кербола
v_inf = 1756.2300957315365                  # из гомановского перелёта (готовое число)
rp = R_JOOL + 200e3

def flyby(h_p, vinf, r=R_JOOL, mu=MU_JOOL):
    rp = r + h_p
    e  = 1 + rp * vinf**2 / mu
    return e, 2 * math.asin(1 / e), rp * math.sqrt((e + 1) / (e - 1))

print("v_j=%.1f  v_esc=%.1f" % (v_j, v_esc))
for h in (200e3, 5e6, 20e6, 100e6):
    e, d, b = flyby(h, v_inf)
    print(f"h={h/1e3:>7.0f} км  e={e:6.4f}  δ={math.degrees(d):6.2f}°  b={b/1e3:8.0f} км")

_, dmax, _ = flyby(200e3, v_inf)
need = math.acos((v_j**2 + v_inf**2 - v_esc**2) / (2 * v_j * v_inf))
print(f"макс δ={math.degrees(dmax):.2f}°,  нужно δ≥{math.degrees(need):.2f}°  → пролётом не уйти")

bb = -2 * v_j * math.cos(dmax); cc = v_j**2 - v_esc**2
v_inf2 = (-bb + math.sqrt(bb * bb - 4 * cc)) / 2
dv = math.sqrt(v_inf2**2 + 2 * MU_JOOL / rp) - math.sqrt(v_inf**2 + 2 * MU_JOOL / rp)
print(f"Оберт при h_p=200 км: v∞ {v_inf:.0f} → {v_inf2:.0f} м/с, Δv = {dv:.1f} м/с")
```
