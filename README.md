# Гравитационный манёвр у газового гиганта: физико-математическая модель пролёта у Юпитера и её верификация по миссии «Вояджер-2»

Проектная работа по курсу **«Введение в авиационную и ракетно-космическую технику»**
(ВАРКТ'26, МАИ, институт № 8, кафедра 806).

В проекте построена замкнутая физико-математическая модель гравитационного манёвра
(«гравитационной пращи») в поле газового гиганта Юпитера на реальных константах
Солнечной системы (NASA/JPL), исследован выигрыш активного импульса в перицентре
(эффект Оберта) и выполнена наглядная проверка модели численным методом
Рунге—Кутты 4-го порядка, подстановкой справочных параметров пролёта станции
«Вояджер-2» у Юпитера и поэтапным сопоставлением с фактическим полётом.

## Быстрый старт

### Вариант 1 — через Nix (`shell.nix`)

```bash
nix-shell
python3 src/sim.py             # расчёт модели, проверка и построение 5 графиков (~10 с)
python3 src/anim.py            # видео out/mission.mp4 с вращением планет и уходом КА
```

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python3 src/sim.py
.venv/bin/python3 src/anim.py
cd report && ../.venv/bin/python3 build.py
```

## Ядро физико-математической модели

1. **Эксцентриситет пролётной гиперболы** (из сохранения энергии и момента импульса):
   `e = 1 + r_p · v∞² / μ`
2. **Угол поворота вектора скорости** в сфере действия планеты:
   `δ = 2 · arcsin(1 / e)` (модуль `v∞` в системе планеты не меняется!)
3. **Прицельный параметр**:
   `b = r_p · √((e + 1) / (e - 1))`
4. **Гелиоцентрический «треугольник скоростей»** (пролёт позади планеты):
   `v_вых² = v_план² + v∞² - 2 · v_план · v∞ · cos(φ_вх - δ)`
5. **Эффект Оберта** (импульс в перицентре для ухода из системы):
   `Δv = √(v∞'² + 2μ/r_p) - √(v∞² + 2μ/r_p)`, где `v∞'` — наименьший корень
   самосогласованной системы `v_esc² = v_план² + v∞'² − 2·v_план·v∞'·cos δ'`,
   `δ' = 2·arcsin(1/(1 + r_p·v∞'²/μ))` (импульс меняет и `v∞`, и `δ`)

|---|---|
| Перелёт Земля → Юпитер (полуэллипс Гомана) | `a_t = 464.04` млн км, `t = 997.7` сут (2.73 г), опережение Юпитера `97.16°` |
| Отлётный импульс с низкой орбиты 100 км | `Δv = 6312.0` м/с |
| Избыточная скорость входа к Юпитеру | `v∞ = 5643.3` м/с (при `v_Юпитера = 13056.7` м/с) |
| Бесплатный заброс к афелию орбиты Сатурна (`1514.5` млн км) | `h_p = 1 368 645` км, `δ = 94.48°`, `Δv = 0` м/с |
| Максимальный поворот у границы атмосферы (`h_p = 200` км) | `δ_max = 158.41°`, афелий `164 228` млн км (`v_вых = 18421.3` м/с) |
| Уход из Солнечной системы (`v_esc = 18464.9` м/с) | нужен `δ ≥ 160.17°` → пассивно невозможен; **эффект Оберта: `Δv = 4.8` м/с** (самосогласованный расчёт с обновлением `δ`; фикс. `δ` даёт `4.29` м/с, −10 %) |
| Проверка методом RK4 (постоянный шаг `20` с, `h_p = 20` тыс. км) | `155.58°` в сфере действия против формулы `155.66°` (`Δ = 0.08°`) |
| Проверка на табличных данных «Вояджера-2» у Юпитера (NASA) | `e = 1.329`, `δ = 97.6°`, выходная скорость **`19.83` км/с** против **`20.03` км/с** (**погрешность `1.0 %`**) |
| Сравнение модели с фактическим полётом | перелёт `997.7` сут против `689` сут (20.08.1977 → 09.07.1979); `v∞ 5.64` против `7.60` км/с; модель требует `Δv = 4.8` м/с, «Вояджер-2» ушёл из системы без топлива |
