# Гравитационный манёвр у газового гиганта: физико-математическая модель пролёта Юла и её верификация по миссии «Вояджер-2»

Проектная работа по курсу **«Введение в авиационную и ракетно-космическую технику»**
(ВАРКТ'26, МАИ, институт № 8, кафедра 806).

В проекте построена замкнутая физико-математическая модель гравитационного манёвра
(«гравитационной пращи») в поле газового гиганта Юла, исследован выигрыш активного
импульса в перицентре (эффект Оберта) и проведена верификация модели численным методом
Рунге—Кутты 4-го порядка и по реальным эфемеридам станции «Вояджер-2» у Юпитера
(NASA JPL Horizons).

## Быстрый старт

### Вариант 1 — через Nix (`shell.nix`)

```bash
nix-shell
python3 src/sim.py                        # расчёт модели и построение 5 графиков (~3 с)
python3 src/jpl_horizons.py --no-network  # верификация по данным «Вояджера-2»
python3 src/anim.py                       # видео out/mission.mp4 с вращением планет
cd report && python3 build.py             # сборка отчёта report/report.pdf
```

### Вариант 2 — через стандартный `venv`

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python3 src/sim.py
.venv/bin/python3 src/jpl_horizons.py --no-network
.venv/bin/python3 src/anim.py
cd report && ../.venv/bin/python3 build.py
```

## Ядро физико-математической модели

1. **Эксцентриситет пролётной гиперболы** (из сохранения энергии и момента импульса):
   `e = 1 + r_p · v∞² / μ`
2. **Угол поворота вектора скорости** в сфере действия планеты:
   `δ = 2 · arcsin(1 / e)` (модуль `v∞` в системе планеты не меняется!)
3. **Прицельный параметр**:
   `b = r_p · √((e + 1) / (e - 1))`
4. **Гелиоцентрический «треугольник скоростей»** (пролёт позади планеты):
   `v_вых² = v_план² + v∞² - 2 · v_план · v∞ · cos δ`
5. **Эффект Оберта** (импульс в перицентре для ухода из системы):
   `Δv = √(v∞'² + 2μ/r_p) - √(v∞² + 2μ/r_p)`
