# Гравитационный манёвр у газового гиганта: физико-математическая модель пролёта Юла и её верификация по миссии «Вояджер-2»

Проектная работа по курсу **«Введение в авиационную и ракетно-космическую технику»**
(ВАРКТ'26, МАИ, институт № 8, кафедра 806).

Модель строит цепочку «перелёт → пролёт → уход/наведение на следующую цель» для системы
Кербола и проверяет её четырьмя независимыми способами, включая реальные эфемериды
NASA JPL Horizons для пролёта «Вояджер-2» у Юпитера. Симулятор KSP как средство проверки
не используется.

## Быстрый старт

```bash
pip install numpy scipy matplotlib imageio-ffmpeg
pip install typst            # только для сборки отчёта

python3 sim.py                       # ~3 с: фигуры 1–6 + summary.json
python3 scale_check.py               # ~15 с: задача трёх тел + фигура 7
python3 jpl_horizons.py --save out/jpl_snapshot.json   # нужен интернет
python3 anim.py --seconds 14         # видео out/mission.mp4 (~80 с)

cd report && python3 build.py        # отчёт report.pdf
```

Без интернета: `python3 jpl_horizons.py --no-network` берёт сохранённый снимок.

## Что считается

| Модуль | Содержание |
|---|---|
| Гомановский перелёт Кербин → Юл | время перелёта, v∞ отлёта/прилёта, Δv, фаза встречи |
| Гиперболический пролёт | `e = 1 + r_p v∞²/μ`, `δ = 2·arcsin(1/e)`, прицельный параметр `b` |
| Послепролётная орбита | афелий, эксцентриситет, условие ухода из системы Кербола |
| Эффект Оберта | импульс в перицентре, добирающий недостающий поворот |
| Задача Ламберта | коридор стартовых условий Юл → Эилу (универсальные переменные) |
| Верификация | 4 уровня: аналитика, 3 тела, эфемериды JPL, литература |

## Ключевые результаты

| Величина | Значение |
|---|---|
| Перелёт Кербин → Юл | 280.7 сут, a = 41.19 млн км |
| v∞ прилёта к Юлу | 1756 м/с |
| Δv отлёта с орбиты 100 км | 1931 м/с |
| Максимальный поворот у Юла | δ = 139.0° (h_p = 200 км) |
| Афелий после пролёта h_p = 200 км | 710.6 млн км |
| Пролёт на афелий Эилу | h_p = 35 096 км, δ = 87.3° |
| Уход из системы | нужен δ ≥ 164.3° → недостижим, Δv = 58.9 м/с в перицентре |
| Ламберт Юл → Эилу | 102 из 210 вариантов (48.6 %) в коридоре v∞ ≤ 1756 м/с |

## Верификация

| Уровень | Что проверяется | Расхождение |
|---|---|---|
| 1 | Численное решение (RK4) против аналитической коники | 0.07° |
| 2 | Модель сфер действия против полной задачи трёх тел | 0.7–2.1° по δ |
| 3 | Модель против эфемерид «Вояджер-2» (NASA JPL Horizons) | **0.03°** |
| 4 | Согласование с литературными данными | качественное |

Дополнительно: фит vis-viva по данным Horizons даёт 2μ = 2.5361·10⁸ против табличного
2.5337·10⁸ км³/с² (0.09 %) — данные «чистые», модель энергии справедлива.
