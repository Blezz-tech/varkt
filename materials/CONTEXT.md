## 2. Требования, которые НЕЛЬЗЯ терять

1. Тема уникальна относительно списка ВАРКТ'26 (файлы CSV в первом архиве).
2. Обязательны **физическая модель**, **математическая модель** и **моделирование на Python**.
3. **КСП (Kerbal Space Program) не должен быть содержанием работы**: ни автопилота на kRPC,
   ни симуляции в KSP как результата. KSP используется только как источник констант
   («система Кербола» — учебная модель планетной системы).
4. Отчёт — **по ГОСТ 7.32-2017**, повторяя структуру и титульный лист образцов
   («варкт.pdf», «Отчёт.docx.pdf», `ref/ksp.docx` — образцы использовались, сами файлы
   в репозитории не хранятся, см. §9).
5. Отчёт делается в **Typst** (исходник `.typ` + собранный PDF), а не в docx.
6. Верификация не через KSP, а через **4 независимых уровня** (см. §6).

## 4. Ключевые численные результаты (не пересчитывать заново без нужды)

**Перелёт Кербин → Юл:** a_t = 41.187 млн км; TOF = 280.7 сут; v∞ отлёта = 2713 м/с;
Δv = 1931.3 м/с (с орбиты 100 км); v_Юла = 4128.7 м/с; v прилёта (гелиоц.) = 2372.5 м/с;
v∞ прилёта = 1756.2 м/с; требуемая фаза = 96.58°.

**Пролёт (углы поворота):** 138.98° при h_p = 200 км (b = 34 268 км, афелий 710.6 млн км);
126.45° при 5 000 км; 102.32° при 20 000 км; 55.23° при 100 000 км; 17.63° при 500 000 км.
Афелий орбиты Эилу (113.5 млн км) достигается при **h_p ≈ 35 096 км** (δ = 87.31°).

**Уход из системы Кербола:** v_esc = 5838.9 м/с на радиусе Юла; требуется δ ≥ 164.32°,
достижимо максимум 138.98° → гравитацией не уйти; эффект Оберта даёт **Δv = 58.9 м/с**
на высоте 200 км.

**RK4 vs аналитика:** δ = 102.256° против 102.322° (0.066°), r_p = 26 229.5 км при заданных 26 000 км.

**Ламберт Юл → Эилу:** 210 вариантов («фаза × время перелёта» 400/700/1000 сут);
102 (48.6 %) попадают в коридор v∞ ≤ 1756 м/с; минимум требуемой v∞ = 23 м/с
(69.3 млн км, TOF 1000 сут).

**JPL Horizons (Вояджер-2, Юпитер, 09.07.1979):** r_p = 721 895 км = 10.098 R_J,
время перицентра 1979-Jul-09 22:00; фит по кольцу 20–120 R_J (N = 194): v∞ = 7.605 км/с,
e = 1.3296, δ_асимпт = 97.55°, b = 1 919 190 км = 26.84 R_J; наклон vis-viva даёт
2μ = 2.5361·10⁸ против табличного 2.5337·10⁸ (0.09 %); δ по эфемеридам 91.16° против
модельных 91.13° (**0.03°**); гелиоцентрическая скорость 9.86 → 20.03 км/с (+10.17).

**Задача трёх тел (фигура 7):** h_p = 20 000 км → δ 102.32° / 103.33°, афелий 160.89 / 186.85;

## 10. Замечания по окружению (грабли, уже пройденные)

- **Typst CLI отсутствует** — используется Python-пакет `typst` (`typst.compile(input, output,
  root=..., font_paths=...)`). Пакет собран из WASM, CLI не ставится.
- **ffmpeg в системе нет** — `anim.py` подставляет каталог бинарника из `imageio-ffmpeg`
  в `PATH` и задаёт `matplotlib.rcParams["animation.ffmpeg_path"]`.
- **Воркспейс сбрасывает каталоги с именами `out/`, `build/`, `dist/`** между сессиями:
  `voyager_ksp/out/` пропадал и был перегенерирован прогоном всех четырёх скриптов.
  Если результаты внезапно исчезли — просто запустить скрипты заново (~100 с суммарно
  с анимацией, ~30 с без неё).
- `pdftotext` нет; для чтения PDF используется `pymupdf` (`import pymupdf`).
- JPL Horizons: `START_TIME < STOP_TIME` обязательно; центр Юпитера — `CENTER='500@599'`
  (или `'@599'`, без `@` — барицентр); `VEC_TABLE='2'`, `CSV_FORMAT='YES'`.
- В Typst (0.15.2 через пакет) осторожно с: `ddot` → `dot.double`, `varepsilon` → `epsilon`,
  `#set raw(line-spacing:)` не существует, `par(spacing:)` вместо несуществующего `par-indent`,
  подчёркивания в тексте (`М8О-___БВ-26`) требуют экранирования `\_`, `*`-пункты списков
  с формулами лучше заменять на `+`.
- **Typst 0.15.2: селектор `figure.where(kind: "image")` (строка) НЕ матчится** — у figure
  `kind` это функция-элемент, а не строка. Писать `kind: image` (без кавычек), иначе подписи
  рисунков рендерятся как «Рис. 1. …» вместо «Рисунок 1 — …». `kind: table` без кавычек —
  рабочий вариант (таблицы «Таблица N — …» всегда были корректны).
- Системный Python в песочнице защищён (PEP 668) — зависимости ставить в `.venv`
  (`python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`).
- `*.pdf` в `.gitignore`: `report/report.pdf` в Git не хранится, собирается локально
  скриптом `report/build.py`.
- Структура репо: код в `src/`, `OUT` считается от корня (каталог над `src/`), результаты
  всегда в `./out`. Скрипты запускать из корня репозитория.
- JPL Horizons из песочницы недоступен (сеть ограничена) — использовать
  `src/jpl_horizons.py --no-network` (работает с `out/jpl_snapshot.json`).

## 11. Как продолжить в новом чате
